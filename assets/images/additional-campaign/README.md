# Camelot Flows Additional Campaign Assets

Generated on 2026-04-30 for optional use across the static site and WordPress theme.

## Raster WebP Assets

- `cf-campaign-home-solo-workshop.webp` - homepage proof or post-hero credibility section.
- `cf-campaign-about-process-board.webp` - about page workshop/process visual.
- `cf-campaign-services-flow-map.webp` - homepage services or round-table transition image.
- `cf-campaign-merlin-interface.webp` - Merlin page hero/supporting product visual.
- `cf-campaign-arsenal-blueprint.webp` - Arsenal page product-showcase hero or card.
- `cf-campaign-work-handoff.webp` - Work With Me page handoff/engagement section.
- `cf-campaign-case-results.webp` - Case Studies page results/collage visual.
- `cf-campaign-agency-production.webp` - For Agencies page white-label production visual.

## Animated SVG Assets

- `cf-campaign-flow-routes.svg` - abstract animated route map for the homepage services divider.
- `cf-campaign-merlin-signal.svg` - animated signal orb for the Merlin page or contact CTA area.

## Usage Notes

These are additive campaign assets. Keep the existing live images in place until a specific placement is selected, then reference these via `assets/images/additional-campaign/<filename>`.

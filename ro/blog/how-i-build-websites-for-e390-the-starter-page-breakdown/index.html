Un website de 390 euro suna a gluma sau a capcana. Iata adevarul: este o prezenta web reala, functionala, gata pentru clienti. Si in 2025, vine cu AI inclus.

Doua Pachete, Un Pret

Fiecare proiect de 390 euro este unul din doua lucruri:

  • Landing Page + Chatbot Inteligent – O pagina unica, axata pe conversie, care capteaza lead-uri non-stop, cu un chatbot AI de baza ce califica vizitatorii, raspunde la intrebari frecvente si directioneaza solicitarile serioase direct in inbox-ul tau.
  • Site Portfolio (5-10 pagini) + Chatbot + Auto-Blog – Un site WordPress complet cu pagini de servicii, despre, portofoliu si contact – plus acelasi chatbot inteligent, plus un sistem auto-blog ce genereaza continut relevant si mentine site-ul activ fara sa scrii tu un cuvant.

Ambele optiuni au scop fix. Tu alegi ce se potriveste situatiei tale.

Ce Inseamna Chatbotul Inteligent

Nu este un widget FAQ. Chatbot-ul este alimentat de un workflow n8n conectat la Claude AI. Citeste lista ta de servicii, intelege preturile tale si poarta conversatii naturale cu potentialii clienti – 24 de ore pe zi, in orice limba scriu ei. Cand cineva este gata sa angajeze, capteaza detaliile lor si le trimite direct la email-ul sau CRM-ul tau.

Fara agent de chat live. Fara lead-uri pierdute la 2 noaptea.

Ce Inseamna Auto-Blog

Functia auto-blog (disponibila in pachetul portfolio) se conecteaza la un workflow n8n care genereaza si publica articole relevante conform unui program. Nu este spam – este continut targetat pe cuvinte cheie, specific nisei tale, care iti construieste amprenta SEO in timp ce dormi. Poti revizui si aproba fiecare articol sau il setezi pe pilot automat complet. Alegerea ta.

De Ce Functioneaza Economia

Site-ul in sine este construit pe un template WordPress rafinat – curat, rapid, perfect pe mobil. Am construit acest template de zeci de ori, deci timpul de configurare este minimal. Asta mentine pretul scazut.

Stratul AI (chatbot + auto-blog) ruleaza pe instrumente pe care le-am configurat deja pentru workflow-ul propriei mele agentii. Pornirea unei instante pentru proiectul tau nu ma costa aproape nimic extra. Ceea ce platesti este timpul meu pentru a-l personaliza dupa brandul tau, a scrie textele, a configura automatizarea si a-l lansa. Atat.

Pentru Cine Este

  • Freelanceri si consultanti care au nevoie rapid de o prezenta web profesionala
  • Afaceri locale fara prezenta online acum
  • Furnizori de servicii care vor lead-uri ce vin in timp ce ei lucreaza
  • Oricine a primit o oferta de 2000-5000 euro pentru un website si vrea un punct de intrare mai inteligent

Ce Nu Este

Acesta este un pachet cu scop fix – nu un design personalizat de la zero, nu un magazin ecommerce, nu o aplicatie web complexa. Daca ai nevoie de acestea, le ofer la preturi diferite. Pachetul de 390 euro este construit pentru viteza si eficienta, nu pentru flexibilitate infinita.
